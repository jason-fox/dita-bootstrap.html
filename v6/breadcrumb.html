Breadcrumb

Indicate the current page’s location within a navigational hierarchy that automatically adds separators via CSS.

Adding breadcrumbs

Breadcrumbs are not included by default. You can add a breadcrumb component to each page by setting the parameter --args.breadcrumbs=yes 

dita --input=path/to/your.ditamap \
     --format=html5-bootstrap \
     --args.breadcrumbs=yes

Dividers

Dividers are automatically added via CSS. They can be changed by setting the parameter --bootstrap.breadcrumb.divider. 

dita --input=path/to/your.ditamap \
     --format=html5-bootstrap \
     --args.breadcrumbs=yes \
     --bootstrap.breadcrumb.divider='>'
