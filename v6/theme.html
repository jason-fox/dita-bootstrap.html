Theme

Combine one of three theme utilities with the Bootstrap theme color classes to set color and background-color pairings on any element, just like component variants.

Overview

Take any of the Bootstrap theme color classes and add theme-contrast, theme-subtle, or theme-muted to set a predefined color and background-color pairing. Then optionally add theme-border to set a predefined border color.

Contrast

How theme values are built up

Every Bootstrap theme color class used in this documentation, whether on a standard DITA element or the specialization @theme attribute), or on one of the --bootstrap.theme.* command line parameters below, is a hyphenated compound of one of the 8 Bootstrap theme colors:

  • accent
  • danger
  • info
  • inverse
  • primary
  • secondary
  • success
  • warning

With a suffix indicating the theme's style

  • -contrast pairs the solid background with the contrast text color
  • -subtle pairs the low-contrast background with matching text
  • -muted pairs the low-contrast background with muted text
  • -border sets a predefined border color on its own
  • -subtle-border combines -subtle and -border

These values are a shorthand notation corresponding to the @outputclass="theme-{color} theme-{contrast|subtle|muted} theme-{border} attribute values.

The following command line parameters optionally consume a theme value to style layout regions:

--bootstrap.theme.header
Page header theme. Defaults to primary-contrast
--bootstrap.theme.footer
Page footer theme. Defaults to none
--bootstrap.theme.sidebar
Sidebar theme. Defaults to none
--bootstrap.theme.topbar
Top bar theme. Defaults to none
--bootstrap.theme.content
Main content area theme. Defaults to none
--bootstrap.theme.scrollspy
Scrollspy menu theme. Defaults to none
--bootstrap.theme.body
Page <body>. Defaults to none
